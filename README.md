# NLP — Fall 2026
UT Austin's Graduate NLP course taken in Fall 2026.

This is a personal learning log based on a professional experiment, while taking the above course. I'm intentionally disabling code completion and AI features. I use VS Code for development and disabled copilot and inline suggestions.

## The rules

- No Copilot or inline completion. Disabled at the workspace level (see `.vscode/settings.json`).
- If I can't explain a line, it doesn't go in.
- For concept clarification or debugging, AI could be used provided it sits outside the editor. But I am not allowed to copy-paste code from it.
- I use Claude Pro version.

## What the course allows

The Fall 2026 syllabus permits generative AI on a partial basis:
allowed for understanding concepts and as a coding assistant on
programming assignments, with the requirement that you devise the
high-level solution yourself, review output critically, and disclose
use per course policy. Not permitted on the midterm, online exercises,
or final quiz. My rules above are deliberately stricter than this.

## What this is not

This repository contains NO coursework solutions, no assignment code, and no course materials. It is my own notes and scratch implementations.

## Sources

UT Austin NLP course materials were created by Professor Greg Durrett and are [publicly available](https://www.cs.utexas.edu/~gdurrett/courses/online-course/materials.html). Fall 2026 is taught by Professor Jessy Li and has slightly different grading structure. All notes here are my own writing.
